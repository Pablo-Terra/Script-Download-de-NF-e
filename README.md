# 👔 Script-Download-de-NF-e

Protótipo de bot para automatizar o download de notas fiscais eletrônicas (NF-e), reduzindo o trabalho manual da equipe fiscal da Barreto Consultorias.

## 📌 Sobre o projeto

Baixar notas fiscais uma a uma consome um tempo que a equipe fiscal poderia usar em tarefas mais estratégicas. Este script automatiza esse processo: navega pelo portal correspondente e baixa os arquivos de forma automatizada a partir de uma lista de referência.

## ⚙️ Funcionalidades

- Automação de navegador para acessar o portal de notas fiscais
- Download automatizado dos arquivos de NF-e
- Leitura de lista de referência para orientar as buscas

## 🛠️ Tecnologias utilizadas

- Python 3
- Selenium WebDriver (Microsoft Edge)
- pandas (leitura/manipulação de dados tabulares)

## 🚀 Como executar

**Pré-requisitos:**
- Microsoft Edge instalado
- Edge WebDriver compatível com a versão do navegador ([download aqui](https://developer.microsoft.com/microsoft-edge/tools/webdriver/))
